# CajaSmart Reels

Private storage for CajaSmart Instagram Reels.

- `reels/` — rendered MP4s (`<date>-<familia>.mp4`) with their contact sheets (`.png`). Composio pulls these at publish time; the repo stays private.
- `kit/` — reference code (logo builder, voice, two render styles, finish script). The topic registry lives in the claude.ai project doc `reels/used_topics.md`.
